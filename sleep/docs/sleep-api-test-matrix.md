# Sleep API test matrix

Run the application with the `api-test` profile.  It freezes the application clock at **September 5th, 2026** (`America/Sao_Paulo`); production has no fixed-instant property and uses the real system clock.

All requests use the implemented route (`/sleep-logs`) and HTTP status is part of the expected result.  `L` is last night, `1`, `7`, `30`, and `365` are history windows.  The `30` request intentionally omits `historyDays` to exercise the default.
